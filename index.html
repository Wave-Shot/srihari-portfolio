Document Intelligence Pipeline - Autonomous Multi-Agent System for Extracting Structured Data from Arbitrary Documents

Python API | Sarvam Document AI (Vision 1.5) | Sarvam Digitise | Groq | Pydantic | Pytest HTML | CSS | Javascript

Developed a multi-agent Document Intelligence Pipeline that automates document classification, information extraction and validation. The system uses Sarvam Document AI and Sarvam Digitise for OCR and document processing, Groq for intelligent extraction and reasoning and FastAPI + Pydantic for building and validating APIs.The pipeline consists of three agents: Classification Agent, Extraction Agent, and Validation Agent, enabling structured, reliable information extraction from unstructured documents.

Vaani Support - Multilingual Dialect-Aware AI Voice Customer Support System

Next.js | Sarvam AI APIs | Saaras v3| Sarvam-M | Bulbul v3 | MongoDB Atlas

A multilingual, dialect-aware AI voice customer-support system designed to reduce wait times, repetitive support queries, and language barriers. It converts user's speech to text using Sarvam Saaras v3, identifies the user's intent and routes queries to various departments, generates an LLM-based response and converts it back into natural speech using Sarvam Bulbul v3. It also uses MongoDB for storing conversation sessions and analytics with a Next.js frontend.

A research project on real-time sentiment analysis for dynamic public opinion insights.
